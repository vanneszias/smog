# SMOG

Sign language learning platform: a TanStack Start site on Cloudflare Workers (`apps/site`) and an Expo app (`apps/mobile`), with all logic in `packages/*`.

```bash
bun install
bun dev             # site + mobile dev servers
bun run release:check
```
