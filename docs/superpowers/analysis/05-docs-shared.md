### SEARCH_ALGORITHM.md (full rules; verified against code packages/hooks/src/gestureSearchRanking.ts)
Two search paths:
- Native: `apps/native/hooks/useGestureData.ts` calls Convex query `gestures.searchForNative`. `useOptimizedSearch` debounces (300ms default) query + category filters, requests more results as visible page grows, exposes loading + timing state. Search text goes to Convex; analytics receives ONLY query length, category count, result count, has_results.
- Web/in-memory: `@smog/hooks` `searchGestures`/`useGestureFiltering` for already-loaded lists.
Ranking algorithm (code-verified detail):
1. Query trimmed; empty/whitespace -> [].
2. Lowercased comparison. For each gesture, for each field value (skip empty): exact (valueLower === queryLower), else startsWith, else word-boundary regex `\b<escaped query>` on lowercased value. Non-matching -> score 0.
3. Field weights: name 100, concept 50, category 30, info 10.
4. Match multipliers: exact 1000, startsWith 500, wordBoundary 250, fuzzy 150. Score = multiplier * fieldWeight (e.g. exact name = 100000, exact concept 50000, startsWith name 50000, wordBoundary info 2500).
5. Case-sensitive bonus (option `caseSensitiveBonus`, default true): if the original value `.includes(query)` (case-sensitive) score *= 1.1 (note: applied to score even when 0, no effect).
6. Best (highest) score over all fields/values chosen; record matchedField and matchType.
7. Gestures with no direct match go to Fuse.js: options `ignoreLocation: true, includeMatches: true, includeScore: true, minMatchCharLength: 2, threshold: fuseThreshold (default 0.4), useExtendedSearch: false`; keys name(weight 1.0), concept(0.5), _normalizedCategories(0.3), info(0.1) (weights = FIELD_WEIGHT/100). fuseScore = 1 - result.score (result.score 0=perfect); matchedField = first match key (name/concept/_normalizedCategories->category/else info; default "info"); score = 150 * fieldWeight * fuseScore.
8. Filter `score >= minScore` (default 0). Sort score DESC, tiebreak `name.localeCompare` ASC.
Types: `SearchableGesture {_id?, categories?: ({_id,name}|undefined)[] (web), category?: string[] (native), concept: string[], id?, info: string, name}`; `MatchType = "exact"|"startsWith"|"wordBoundary"|"fuzzy"`; `MatchField = "name"|"concept"|"category"|"info"`; `ScoredGesture<T> {fuseScore?, gesture, matchedField, matchType, score}`; `SearchRankingOptions {caseSensitiveBonus?, fuseThreshold?, minScore?}`. Exports `searchAndRankGestures(gestures, query, opts)` and `searchGestures(gestures, query, opts)` (returns T[]).
Category filtering (web `useGestureFiltering`): gesture kept if ANY selected category matches (OR logic; NOTE HOOKS.md wrongly says AND), then relevance search on filtered set. With no text query, sort by `sortColumn` ("name" | "category" = first category name) and `sortDirection` asc/desc via localeCompare; with query, keep relevance order.
Tests: packages/hooks/src/__tests__/gestureSearchRanking.test.ts (empty input, case, field matches, ranking, missing results, typo fuzzy).

### PAYMENT_FLOW.md
Purchase: 1) sponsor selects gestures; 2) enters contact details, display text, optional logo, optional invoice details; 3) API asks Remotion to compose preview videos, stores Mux playback IDs; 4) Convex creates `pending_payment` sponsorship rows; server computes authoritative amount from shared pricing (never trust client total; Convex repeats the calc before creating records); 5) API creates Mollie payment, redirect to Mollie hosted checkout; 6) Mollie posts payment ID to `/webhooks/mollie`; 7) server retrieves payment from Mollie, processes only if status `paid`; 8) sponsorships -> `pending_approval`, confirmation/admin emails queued; 9) admin approves/rejects.
Approval: activates sponsorship, publishes sponsored Mux playback ID, sends "live" confirmation. Rejection records reason + correspondence with sponsor. Active sponsorships expire after 1 year; one renewal reminder ~30 days before expiry; expiry restores original gesture video and deletes sponsored Mux asset when possible.
Incomplete payments: hourly check; `pending_payment` older than 24h -> `cancelled` (frees gesture).
Re-edit: admin generates random re-edit token valid 7 days; sponsor updates approved fields without new payment; submission invalidates token and returns sponsorship to review (`pending_resubmission` -> `pending_approval`).
Pricing (packages/config/src/constants.ts): one gesture/year EUR 50.00 (PRICE_PER_YEAR_CENTS=5000); logo option per gesture EUR 10.00 (LOGO_ADDON_CENTS=1000); FIXED_DURATION_YEARS=1; MAX_GESTURES_PER_SPONSORSHIP=10. Total = count*5000 + (logo ? 1000*count : 0) (CODE_STYLE example: 3 gestures with logo = 16000 = EUR160).
Security/data: MOLLIE_API_KEY server-only; Mollie collects card/bank; SMOG stores Mollie payment ID, amount, status, sponsor contact, requested invoice details. Webhook fetches state from Mollie, not from body. Records may need retention for Belgian accounting/tax. Use Mollie test credentials in dev.
