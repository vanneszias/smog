### Auth mechanics (`lib/auth.tsx`)
- Sign-in: `crypto.randomUUID()` state stored in `sessionStorage["smog_oauth_state"]`, `buildAuthorizationUrl({clientId, redirectUri, state})` from @smog/auth, `window.location.assign`.
- On mount: `POST ${VITE_SERVER_URL}/auth/token/refresh` (credentials include; httpOnly refresh cookie) -> `{accessToken, user}`; stored in module memory only.
- If URL has `?code=`: strip query via `history.replaceState`, validate state equals sessionStorage value (else "OAuth state validation failed"), `POST /auth/workos/callback {code}` (credentials include) -> `{accessToken,user}` else falls back to refresh.
- `getAccessToken()` returns cached token unless `isTokenExpired`, dedupes concurrent refreshes; on failure clears session.
- Sign-out: `POST /auth/token/clear` (credentials include), clears analytics identity + memory.
- Context: `authMode: loading|authenticated|unauthenticated`, `isGuest:false`, `guestId:null`, `isHandlingOAuthCallback`.
- oRPC client (`utils/orpc.ts`): `RPCLink url=${VITE_SERVER_URL}/rpc`, adds `Authorization: Bearer <token>` if any, `credentials:"include"`. QueryCache global onError -> toast `Error: <msg>` with "retry" action (invalidateQueries).
- `ConvexProviderWithAuth` uses `useAuthForConvex` (fetchAccessToken = getAccessToken). `ConvexUserSync`: after auth, calls `client.users.getOrCreateUser()` once per workosId and exposes Convex `userId` (`useConvexUserId`); failures remembered per workosId to avoid loops. Lists features wait on this id.

## 2. Sponsor wizard (`/sponsors/`, ~ `routes/sponsors/**`)

Route search: `gestureId?: string`. Entry from gesture detail CTA `/sponsors?gestureId=<id>`; pre-selects that gesture once catalogue loaded, only if selection empty and gesture status is `available`.
Guest-friendly: no login required at any step. All state is in-memory React state (`useSponsorshipForm`), lost on refresh. Steps: `"select" -> "details" -> "preview"` (+ redirect to Mollie, then `/sponsors/success`).

Constants (packages/config/src/constants.ts): `PRICE_PER_YEAR_CENTS = 5000` (EUR 50), `LOGO_ADDON_CENTS = 1000` (EUR 10 per gesture), `FIXED_DURATION_YEARS = 1`, `MAX_GESTURES_PER_SPONSORSHIP = 10` (exported but NOT used by web; server actually allows up to `MAX_SPONSORSHIPS_PER_PAYMENT = 20`; web enforces no max). Pricing helper `calculateSimplifiedPrice(count, includeLogo)` => `{durationYears:1, gestureCount, includeLogo, logoAddonCents: logo?1000*count:0, pricePerGestureCents: 5000(+1000), subtotalCents:5000*count, totalCents}`. `formatPrice(cents, lang)` = `Intl.NumberFormat` currency EUR with locale map en->en-BE, fr->fr-BE, nl->nl-BE (default nl-BE), e.g. "EUR 50,00" style (nl-BE output "€ 50,00").

## 8. Guest mode on web

There is none. `AuthContext` on web omits `continueAsGuest`; `isGuest` always false, `guestId` null. Anonymous web visitors can: browse/search gestures, view gesture detail + QR, view shared lists by link (view-only, or edit tokens require sign-in to edit), buy sponsorships (whole wizard is unauthenticated), use re-edit links, read legal pages. They cannot: create/see lists or save gestures (toast "Meld je aan om gebaren op te slaan"; `/lists` shows sign-in empty state), use account page, admin. `/favorites` just redirects to `/lists`. Guest data (favorites/lists with guestId, 12-month cleanup, `recordGuestConsent`) exists only for the native app; `user_favorites` legacy table still exported in GDPR export. Analytics for signed-out web visitors is an anonymous OpenPanel device profile (only after consent).

## 9. Rewrite gotchas / observations
- Stale i18n copy: `web.sponsors.new.validation.sponsorNameTooLong` says 40 but wizard enforces 35 (server 40); `wizard.maxCharacters` says 10; logo guidelines mention min 800x800 while help says 400x400.
- Wizard does not validate logo MIME (only `accept`), re-edit does; server validates data URL regex + 3M chars.
- `MAX_GESTURES_PER_SPONSORSHIP=10` unused; effective server cap 20 per payment; no client cap.
- Overlay text in main wizard is always == sponsorName; only re-edit exposes separate overlay text (<=100). Overlay phrase "Met de warme steun van:" is hard-coded in Remotion.
- Success page total uses `€` + toFixed(2) instead of formatPrice. Generic `/success` route is dead weight.
- Admin: English hard-coded, single-page tabs w/out URLs, no logs/users UI even though API exists; status filter lacks "cancelled"; CSV has no date-range UI.
- Category delete only for active categories in UI.
- Query persistence limited to the gestures catalogue; lists/sponsorship data always live-fetched.
- Legal texts hard-coded NL only (no en/fr) though app has 3 locales.
- `openInApp` builds `smog:///gestures/<id>` (three slashes) then https fallback after 500 ms regardless of success.
- Language toggle labels come from `languages.*` ("Engels","Frans","Nederlands" in nl).
